# AgriSmart

AI based plant disease detection system and smart irrigation manager.

## Features
- Leaf disease detection
- Crop yield prediction
- Smart irrigation scheduling
- Voice assistant interface
- Firebase integration

## Tech Stack
- React / JavaScript (Frontend)
- Node.js (Backend services)
- Python / TensorFlow / Scikit-learn (Machine Learning Models)
- Firebase

## Dataset & ML Models
The complete dataset and trained `.h5` / `.joblib` models are hosted externally to keep the repository lightweight.
**Download dataset and models from:**
[Google Drive Link / Hugging Face Datasets] (Replace with your link)

## Installation
1. Clone the repository
2. Install frontend dependencies in the respective directories using `npm install`
3. Install backend dependencies using `pip install -r requirements.txt`
4. Place the downloaded dataset and models into their respective directories.

## How to Run
Run the full stack application using the provided script:
```bash
./start_all.sh
```
Or start individual services locally.
